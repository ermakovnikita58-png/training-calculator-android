# Иллюстрации FORGE 10.0.1

Реестр exercise-manifest.json перечисляет имя, группу, источник и файлы каждого упражнения. Лицензированные оригиналы: https://github.com/bryllim/workout-guide и https://github.com/everkinetic/data — CC BY-SA 4.0, копия лицензии и атрибуции в app/src/main/assets/exercise-art. Собственные схемы: scripts/anatomy-drawings.cjs. Для разных вариантов общей техники используются общие изображения; схемы требуют редакционной проверки.

Пять карточек мышц созданы инструментом ImageGen: плечи, грудь, спина, бицепс, трицепс. Остальные карточки — собственные SVG. Общий prompt: synthetic educational anatomical mannequin, gray muscle fibers, target muscle highlighted orange, dark background, no text; target muscle and front/back view changed for each card. Exact returned prompt history is not stored in the source archive. Растровые файлы уменьшены до 480px, WebP quality62; новые генерации после просьбы экономить лимит не выполнялись.

Всего добавленные файлы иллюстраций занимают примерно 15.5 МБ до сжатия APK. Изображения доступны офлайн. Прежние встроенные изображения сохранены в исходном HTML для минимального вмешательства, но новые карточки используют реестр exercise-art.js.
