# Аудит текущей итерации

Основа: предоставленный forge-training-10-complete-kit (10).zip. Android — Kotlin WebView, интерфейс и бизнес-логика в assets/index.html. Хранилище localStorage, ключ forge_v2; источник приложения https://appassets.androidplatform.net сохранён. Исходники и архив сохранены отдельно.

| Область | Факт | Проверка / статус |
|---|---|---|
| Сборка Android | Wrapper, JVM17, SDK36, исправленная тема | Локальная сборка и lint; логи в Review |
| Каталог | 556 исходных названий и групп | Сравнение с оригиналом и тест привязок |
| Выбор упражнения | Разные рисунки, кнопки, назначение | Smoke в Chromium и перезапуск |
| Программы, тренировки | Исходный код сохранён, выбор исправлен | Частичный smoke; полный цикл на Android не проверен |
| Питание, рецепты, статистика, калькуляторы | Исходная реализация сохранена | Полная регрессия не выполнена |
| Backup, CSV, импорт | Исходная реализация сохранена | Повреждённый JSON и большой объём не проверены |
| Камера, Android Back, фон/rotation | Исходная оболочка сохранена | Нужен тест на устройстве |
| Облако | Требует внешней конфигурации | Не проверено |
| GitHub | Репозиторий назван в приложенном плане | Текущее удалённое состояние не проверено; локальный workflow подготовлен |

## Приоритеты следующей итерации
- P0: реальный Android: установка/обновление с той же подписью, экспорт резервной копии и восстановление; потеря localStorage при удалении приложения остаётся риском.
- P0: тест полного цикла тренировки и питания, некорректного JSON, переполнения хранилища и восстановления после сбоя. Миграция хранилища в этой итерации не выполнялась.
- P1: визуальная сверка всех рисунков с названием, оборудованием и техникой; некоторые схемы упрощены и требуют ручной проверки.
- P1: камера, фон/rotation, Back, масштаб текста/TalkBack.
- P2: синхронизация только после настройки backend, два устройства и конфликты; монетизация отдельной задачей.

Регрессионный чек-лист для телефона — README.md. Дорожная карта сохранена отдельно и не помечена выполненной.
