# FORGE 10X — измерения ежедневных действий

Сравнение 11.4.4, коммит e75ca62, и 11.5.0, ветка forge-product-10x. Сценарии повторены 21 ноября 2026 на одном Windows-компьютере. Использованы Chromium 151, Playwright, автономные ресурсы приложения, область 390 × 844, фиксированная дата и одинаковый синтетический дневник.

Один клик или заполнение одного поля считается действием. Время измеряется от первого действия до проверки результата в localStorage. Оно включает ожидания браузера и автоматизации. Ориентация на экране, набор вручную, сканер и скорость чтения Android-пользователя в эти замеры не входят.

| Задача | База, действия / медиана | Цель | 11.5.0, действия / медиана |
|---|---:|---|---:|
| Повторить фактический подход 60 кг × 9 при плане 62,5 кг × 8 | 3 / 70 мс | 1 действие | 1 / 37 мс |
| Повторить сохранённый завтрак целиком | 2 / 84 мс | До 2 действий, 5–10 с в пользовательском тесте | 2 / 86 мс |
| Создать рабочую программу из готового шаблона | 1 / 52 мс | Путь одним действием сохранён, меньше 3 мин для пользователя | 1 / 54 мс |
| Сохранить черновик цикла для одной программы с датами по умолчанию | 3 / 112 мс | Сохранить короткий путь при выборе модели | 3 / 132 мс |
| Ввести с этикетки неизвестный продукт и записать 100 г | 10 / 211 мс | Убрать лишний переход между сохранением карточки и выбором порции | 9 / 169 мс |

Для подхода с изменённым планом число действий уменьшилось втрое. В остальных задачах либо стал короче сценарий неизвестного продукта, либо число действий сохранено. Измерения выполнены по пять раз. Эти прогоны не подтверждают ускорение в 5–10 раз и не измеряют показатели удержания.

## Штрихкод, ошибки и отмена

Исходная браузерная проверка воспроизводила контрольную цифру, поиск локального продукта, получение корректного ответа OFF и сбой сети. В 11.5.0 проверены шесть состояний с заданными ответами: контрольная цифра, локальный результат, полный результат OFF, ошибка сети, отсутствие товара и неполные данные. Два кода дают готовую карточку в тестовом наборе из пяти валидных кодов. Для неполной карточки отдельно прошли ввод и исправление КБЖУ, подтверждение порции и сохранение исходных записей. Значения на 100 мл и порция в миллилитрах проверены по данным дневника.

Повторный ввод подхода сразу после клавиатурного подтверждения оставил одну запись. Отмена после перезапуска вернула прежнее состояние подхода. Отмена добавления еды убрала только последнюю партию, включая запись нескольких продуктов. Доля успешного распознавания реальной камерой, ошибок чтения этикеток и ручных исправлений в эксплуатации неизвестна. Для неё нужен тест одинаковых упаковок на Xiaomi 14 в нескольких условиях и журнал исходов.

## Воспроизведение

Сценарии и подсчёт действий находятся в [скрипте измерений](../scripts/product-10x-metrics.cjs). Путь к ресурсам базы задаёт FORGE_METRICS_ASSETS, имя результата — FORGE_METRICS_LABEL. Вывод сохраняется в test-results/product-10x. В репозитории сохранены [сырые исходные измерения](forge-10x/metrics-baseline.json) и [измерения кандидата](forge-10x/metrics-candidate.json).
