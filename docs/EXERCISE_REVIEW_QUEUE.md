# Очередь проверки техники и изображений

Дата: 2026-11-02. Версия **11.2.2 / versionCode 18**, база 97c1299. Все **556 записей имеют expertVerified=false**. У 348 выбран светлый контур, требующий проверки биомеханики; у **208 not-ready** подходящий контур отсутствует. Упражнения и прежние исходники сохранены.

Стандарты и результаты технической проверки: [ART_REFERENCE_STANDARDS.md](ART_REFERENCE_STANDARDS.md). Полный машинный реестр всех 556 записей: [art-reference-review.json](../artwork/art-reference-review.json). Для каждого not-ready в нём заполнены missingReason, originalFiles, equipment и **requiredReplacement**. Текущие используемые файлы и лицензии: [art-registry.json](../artwork/art-registry.json).

## Общее ТЗ-К для каждой строки not-ready

<a id="contour-brief"></a>

ТЗ-К ниже передаёт общие поля requiredReplacement; снаряд и точное название уточняются в каждой строке. Это заказ иллюстрации, а не готовое экспертное описание упражнения.

| Поле requiredReplacement | Обязательное требование |
|---|---|
| type | EXERCISE_TECHNIQUE_ART |
| style | Тонкий белый/светло-серый анатомический контур, прозрачный SVG на поверхности #101912; без градиентов, объёмной модели и цветной заливки мышц |
| equipment | Снаряд из соответствующей строки; при расхождении с точным названием нужна редакционная сверка, случайная подстановка недопустима |
| poses | Исходное и конечное положения соответствуют точному названию; учитываются сторона, хват, опора, положение сидя/стоя/лёжа и вариант движения. Для статического удержания не придумывать движение |
| size | viewBox 512×512; тело, снаряд и опора помещаются целиком |
| rights | Оригинальный вектор проекта либо прослеживаемый источник CC BY-SA 4.0 с авторством и описанием производных изменений |
| doNotUse | Другое упражнение, 3D-анатомия, фотография или CSS-инверсия |

Все 208 строк ниже заказывают ТЗ-К с индивидуальным снарядом и точными положениями своего названия. Поля общего ТЗ совпадают у всех 208 записей реестра. Исходные файлы сохранены в originalFiles, но они не выбираются как подходящая техника. Достаточность двух фаз и их соответствие должны быть проверены после получения иллюстрации.

## Очередь спортивной и редакционной проверки

Все 348 упражнений с выбранным контуром также остаются в очереди: наличие файла и лицензии, совпадение снаряда в метаданных и успешный raster QA не подтверждают биомеханику. Нужно последовательно сверить каждую пару, сторону, хват, опору, суставные положения, траекторию и читаемость линий в реальном размере. Совместное использование пары для темпа или паузы допустимо только после проверки точного варианта. Подтверждённых экспертных статусов нет.

Отдельное описание техники по прежней редакционной очереди требуется для «Вакуум живота», «Аэробика низкой интенсивности», «Сведение гантелей перед грудью стоя». Остальные редакционные инструкции также требуют профильной проверки; этот документ не подтверждает их экспертную правильность. Предыдущий [visual-review-register.json](../artwork/visual-review-register.json) содержит редакционные и исторические сведения; для выбора текущего рисунка приоритетен art-registry.json.

41 историческая запись с одинаковыми исходными фазами не означает 41 новую иллюстрацию: эти старые исходники сохранены, но многие исключены из текущего выбора по стилю. Среди 348 текущих выбранных пар нет статуса identical-source-frames. Это не доказывает, что две разные картинки корректно описывают движение. Новые материалы принимаются после технической, зрительной и спортивной экспертной проверки, а не после изменения числа готовых файлов.
