Спецификация версии **11.2.1 / versionCode 17** описывала вариант, который пользователь отклонил. Её результаты сборки, размеры APK и старые снимки не являются результатами проверки текущей версии. Полный исторический текст доступен в коммите 97c1299573b7926a1af5a7384b8242e979e6bbec.

Актуальный отчёт для **11.2.2 / versionCode 18**, ветка fix-art-reference-standards: [ART_REFERENCE_STANDARDS.md](ART_REFERENCE_STANDARDS.md). Полная очередь недостающих контуров: [EXERCISE_REVIEW_QUEUE.md](EXERCISE_REVIEW_QUEUE.md). Изменённые файлы: [ART_REFERENCE_CHANGED_FILES.md](ART_REFERENCE_CHANGED_FILES.md).

## Что отменено

- Упрощённые общие SVG не используются вместо реалистичных изображений групп. Для MUSCLE_GROUP_ART требуются серебристая объёмная анатомия и оранжевая целевая область; кардио и мобильность остаются нейтральными комплексными категориями.
- Объёмные цветные схемы упражнений не считаются подходящими EXERCISE_TECHNIQUE_ART. Для техники нужен тонкий светлый контур на тёмной поверхности с правильными снарядом, опорой и положениями.
- CSS-инверсия или осветление изображения не подтверждают его стиль и технику. Отдельные белые фоновые слои исходных контурных SVG удалены в производных файлах с сохранением геометрии контура; исходники сохранены.
- Исторические заявления о 916 отображаемых файлах и 451 паре не описывают текущий выбор ресурсов. Текущие пути, роли, SHA256 и статусы заданы в [art-registry.json](../artwork/art-registry.json).

## Сохранённая структура библиотеки

Каталог содержит те же 556 упражнений и 14 групп. Общие компоненты обслуживают библиотеку, выбор упражнения в тренировку и редактор программы. Поиск, фильтры, карточка техники, локальные заметки и фотографии остаются частью существующего приложения. Фотография пользователя хранится отдельно от системного рисунка и не становится системной контурной схемой.

Стек навигации: основные экраны → группы → список → карточка. Состояние библиотеки хранится в forge_exercise_ui_v1, данные пользователя — в forge_v2; существующий JSON-экспорт используется для копии данных. В блоке работающих мышц внутри карточки теперь показывается реалистичное изображение основной группы из MUSCLE_GROUP_ART, вспомогательные мышцы перечислены текстом. Прежняя условная схема из этого блока убрана.

Редакционные описания техники и лицензированные изображения требуют спортивной экспертной проверки. Для всех 556 записей expertVerified=false. Наличие файла, лицензии, двух фаз, успешного теста или контактного листа не означает правильную биомеханику.
