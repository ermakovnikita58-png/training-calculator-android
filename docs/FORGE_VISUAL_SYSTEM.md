# FORGE Visual System — библиотека и техника

Спецификация и отчёт, 2026-11-02. Версия **11.2.1 / versionCode 17**. База — FORGE Performance UI 11.2 (`f83d306f6c8f4b8e2de473abffc985789fb54549`), отдельная ветка `forge-exercise-visual-system`. База включает исправления навигации и Nutrition Coach 11.1. В main изменения не объединялись; исторические ZIP не используются как источник сборки.

## P0: исходный аудит

556 неизменных имён/групп каталога, 14 групп. Исходный реестр содержит 367 записей с лицензированными векторными рисунками и 189 с собственными упрощёнными схемами. Уникальных пар файлов 453, физических SVG 904; в exercise-art 908 файлов с документацией, 16229704 байта. Совместное использование файлов не всегда ошибка: пауза/темп могут иметь одинаковые положения. Оно требует проверки, если меняются снаряд, опора, сторона или траектория.

У прежних 556 записей обнаружено только 28 наборов шагов: например, часть разных упражнений на пресс/кардио получает одинаковую инструкцию. У пяти групп растровые изображения, у остальных — другая SVG-модель. В старом SVG найдены некорректные координаты путей. Новый интерфейс устраняет разнородность, сохраняя оригиналы и обозначая условность новой карты.

## Общие компоненты

Используются общие токены `performance-tokens.css`: фон #0B1016, поверхность #172019, текст #EFF5E9, вторичный #9BA99B, акцент #D1FF63. Радиусы 16/20/24px, шаг отступов 8px, цель нажатия 48px. Новых обязательных сетевых ресурсов нет.

Одна группа-карточка, один компонент строки упражнения, один компонент техники для библиотеки и выбора в тренировку/программу. Имена, счётчики и данные берутся из существующего каталога. Новые файлы — редакционные метаданные для этих же имён, а не второй дневник или отдельный каталог пользовательских упражнений.

Группы: одинаковые слоты изображения 96×112 CSS px, единая модель и подсветка; явные название/счётчик/раскрытие. Список: название, оборудование, группа, движение, уровень; поиск, три фильтра и порции по 40 записей. Резервирование размеров изображения исключает изменение размеров карточки при загрузке. `object-fit:contain` сохраняет рисунок целиком. Карточка техники: фиксированная структура, два места для фаз, исходные сведения программы вместо универсального назначения подходов и отдыха, мышцы, семь блоков техники, заметки, фото и авторство.

Все новые компоненты используют существующие тёмные поверхности. Лицензированные контурные SVG отображаются светлыми на тёмном фоне через CSS, без изменения исходных файлов. Личные фотографии не получают этот фильтр. Для пользователя остаются доступными авторы и ссылка на источник.

## Изображения и проверка

Оригиналы и сведения CC BY-SA4.0 сохраняются. Собственные фотографии всегда имеют приоритет; отказ записи не должен удалять предыдущее фото. Подтверждение существования файла/снаряда в метаданных не равно экспертной проверке позы. Для каждого материала фиксируются технический статус, источник, совместное использование и очередь проверки.

Недостоверное совпадение не подменяется случайным упражнением. Фирменная заглушка применяется адресно, с объяснением причины. Упрощённые исходные схемы явно отделяются от сверенных по источнику рисунков. Все556 упражнений нельзя объявлять экспертно проверенными.

Общая SVG-карта областей тела — собственная условная схема с одинаковыми фронтальным и задним видами. Основная область выделяется оранжевым, вспомогательная — лаймовым, подписи дублируют цвет. Это не модель процентов активации и не клинический анатомический атлас. Мелкие мышцы не визуализируются отдельно. Кардио и мобильность используют нейтральный полный вид, а не вымышленную единственную целевую мышцу. Существующие растровые оригиналы не удаляются. Фотореалистичная профессиональная анатомия и экспертная сверка модели остаются отдельной работой.

## Описание техники

Структура: исходное положение, движение, положение корпуса/суставов, дыхание/контроль, завершение, ошибки, подсказки и особенности варианта. 74 семейства дополняются оборудованием, опорой, стороной, хватом, углом и темпом. Статические удержания не получают инструкцию повторять подъём/опускание; жим в тренажёре не получает указание класть штангу на стойки. 514 записей — редакционные черновики, 39 — черновики растяжки/мобильности/плавания для профильного специалиста, 3 — требуют отдельного описания. Все имеют `requires-specialist-review`.

Для неизвестной техники выводится необходимость проверки, без универсальной придуманной последовательности. Полный реестр: [visual-review-register.json](../artwork/visual-review-register.json); приоритеты и названия: [EXERCISE_REVIEW_QUEUE.md](EXERCISE_REVIEW_QUEUE.md).

Основания для сверки: [ACE library](https://www.acefitness.org/resources/everyone/exercise-library/), [NASM library](https://www.nasm.org/workout-exercise-guidance), [Everkinetic](https://github.com/everkinetic/data), [атрибуция Workout Guide](https://github.com/bryllim/workout-guide/blob/main/ATTRIBUTION.md). Русские редакционные инструкции не означают персонального назначения; экспертная верификация отдельно от технической.

## Навигация и состояние

Стек: основные экраны → библиотека групп → список/фильтры → карточка. Закрытие карточки оставляет тот же DOM списка и прокрутку. Список → группы обрабатывается общим Android/browser Back до выхода из библиотеки. Поиск, оборудование, тип и сложность сохраняются как UI-состояние; дневник forge_v2 не сбрасывается.

Используются прежний `ForgeNavigation`, браузерный sentinel и AndroidX Back. Новый `surfaceOpened()` синхронизирует маршрут после замены содержимого карточки, чтобы она восстанавливалась после reload/пересоздания. Изменения библиотеки хранятся отдельно в `forge_exercise_ui_v1`. Заметки/фото остаются в `forge_v2`, экспортируются прежним JSON и не теряют предыдущее значение при переполнении хранилища. Не менялись applicationId, адрес WebView, формат питания/рецептов/тренировок и расчёты Coach.

Раздельных фотографий продуктов/рецептов среди 948 файлов изображений проекта нет. Дневник питания и редактор рецептов используют прежние компоненты Performance UI; пользовательское содержимое не заменялось.

## Оставшиеся ограничения и проверка телефона

Не выполнены физические predictive-жесты Android 13–16, системная кнопка Back, IME/системные панели/шрифт/TalkBack, системный выбор фото, камера, установка поверх приложения пользователя, убийство процесса. Браузерные reload/Back/загрузка файла не доказывают эти сценарии. Инструментальные тесты нажимают системную кнопку, а не имитируют край экрана.

Сначала сохраните JSON-копию в настройках. Распакуйте ZIP и откройте APK через «Файлы». При совпадающей подписи Android предложит обновление; прежнее приложение удалять не нужно. При конфликте подписи сохраните данные и используйте совместимую сборку. Проверьте: Программы → библиотека → группа → карточка → жест назад возвращает к тому же списку/поиску → назад к группам → программам. Затем добавьте заметку/фото, перезапустите приложение, проверьте активную тренировку и питание. Расширенный чек-лист: [ANDROID_QA_CHECKLIST.md](ANDROID_QA_CHECKLIST.md).

Нельзя объявлять всю технику или изображения экспертно проверенными, новую условную карту — профессиональным клиническим атласом, а Debug APK — стабильным релизом для всех устройств. Google Play и реальные платежи не используются.
