# FORGE Performance UI · v1

Рабочая спецификация от 2026-11-02. База: `nutrition-coach-11-1`, с сохранённым исправлением навигации из PR #5. Отдельная ветка `forge-design-system-v1`; main не изменяется.

## Направление

Оригинальный спортивный интерфейс: графитовый фон, спокойные зелёные поверхности, лаймовое основное действие, крупные числовые результаты. В новом вложении нет визуальных изображений интерфейса, поэтому исходной служит заданная палитра. Логотип и stroke-иконки — локальная оригинальная SVG-графика; анатомические иллюстрации и их лицензии сохраняются.

Источник токенов: `performance-tokens.css`. Совместимые aliases старых переменных позволяют постепенно обновлять действующие компоненты без удаления функций.

## Компоненты

Общие поверхности и metric cards; primary/secondary/quiet/danger buttons; поля и поиск; сегменты и вкладки; exercise card; set row; nutrition summary; SVG progress chart с клавиатурным выбором точки; пустые/загрузочные/ошибочные состояния; toast; компактные sheets для небольшого ввода и полные редакторы для сложного. Системные confirm сохраняются для существующих синхронных опасных операций.

Нижняя панель: Главная / Тренировки / Питание / Программы / Прогресс. Профиль и настройки — в шапке. Глубокие редакторы и карточки закрывают панель; высота навигации измеряется, а не предполагается фиксированной.

## Правила данных и доступности

Новые обзоры читают существующие записи. Нулевое значение отличается от отсутствия данных. В production нет демонстрационной истории. Формулы Coach, ключ forge_v2, applicationId и WebView origin неизменны. Параметры внешнего вида отделены от дневника.

Кнопки имеют названия, выбранные вкладки — aria-current/aria-selected, числовые графики — текстовое представление и клавиатурное управление. Фокус не остаётся в скрытом экране. Цвет сопровождается подписью; анимация не является единственным сигналом.

Статусы реализации и фактические результаты проверок ведутся в UX_AUDIT.md. Эта спецификация сама по себе не означает прохождение Android-проверок.

## Проверенные значения и реализация

Контраст токенов: основной текст/поверхность15.04:1; вторичный текст/поверхность6.80:1; тёмный текст/лайм14.66:1. Это значения палитры, не полный аудит каждого старого вложенного элемента.

Компоненты и переиспользуемые функции находятся в performance-ui.css / performance-ui.js: heading, section, card, metric, button, macro, empty, chart и SVG icon. Обновляются те же корневые секции приложения. Активная тренировка использует нижнюю панель записи вместо пяти вкладок; кнопка «Обзор» возвращает к ним.

18 фактических скриншотов и автоматические геометрические/PNG-проверки: [отчёт](PERFORMANCE-UI-VERIFICATION.md).
