# FORGE Performance UI v1 — проверка 2026-11-02

Версия приложения **11.2.0 / versionCode16**. Ветка `forge-design-system-v1` создана от `nutrition-coach-11-1` (`01e432b`), затем перенесён проверенный коммит навигации `ae0c34d` (локальный cherry-pick `884b14a`). Открытые PR не объединялись, main не изменялся. Сборка использует исходники репозитория, без выбора исторических ZIP.

## Сохранение функций и данных

- `applicationId=ru.trainingcalculator.app`, `https://appassets.androidplatform.net`, ключ `forge_v2` сохранены. Сброса/очистки и разрушающей миграции нет.
- `nutrition-coach-core.js`, формулы, диапазоны и контрольные значения Coach не изменены относительно 11.1. Пять шагов, ручное поддержание, история целей, анализ 14/21 дней и подтверждения сохранены.
- Каталог 556 упражнений, файлы иллюстраций, реестр соответствий и лицензии не изменены. В миниатюрах активной тренировки теперь используется тот же реестр ForgeArt.
- Пять разделов читают тот же state. Представления home/plan/progress заменены через адаптер существующих n8-root; второй дневник/калькулятор и демонстрационные production-данные не создавались.
- Продукты/избранное/сохранённые рационы/рецепты/штрихкод используют прежние обработчики. Просмотр дат питания группирует существующие foods; новые записи добавляются за сегодня с явным переходом на сегодня.
- Добавлены видимые действия удаления последнего подхода и замены незавершённого упражнения. Упражнение с отмеченными подходами не заменяется с потерей результатов. Отмена выбора не оставляет скрытого режима замены.
- Вес/повторы сохраняются существующим n8EditSet при вводе; DOM ввода и нижняя кнопка не пересоздаются при blur. Это устраняет потерю клика после изменения веса.
- `forge_performance_ui_v1` хранит только выбранный день, параметры представления и срок таймера. Срок существующего таймера восстанавливается только для того же active.id. Этот UI-кэш не является вторым дневником; JSON-экспорт дневника не включает отдельные UI-предпочтения.

## Выполненные проверки

`npm test` включает прежние 61 unit-тест Coach, 18 регрессионных сценариев, проверку 556 упражнений, browser-regression, Coach E2E, navigation E2E и новый performance-browser.

Новые сценарии: пять вкладок и выбранное состояние; обзор без изменения forge_v2; фактические итоги/история питания и reload; Coach Back; компактный sheet; отмена выхода из несохранённого рецепта/программы; пять вкладок аналитики и выбор точки графика клавиатурой; добавление/удаление подхода; замена и отмена замены; сохранение ввода, активной тренировки и срока отдыха при reload; вложенная библиотека/Back; уменьшенное движение; увеличенный веб-текст; отсутствие переполнения и ошибок JS при **320/360/390/412 CSS px**. Прежний navigation E2E также проверяет поворот viewport.

Скриншотные проверки при 360/390: считываются PNG-пиксели фона #0B1016 и лаймового выбранного состояния, проверяются геометрия шапки/заголовка/нижней панели и цели нажатия 48px. Это проверка скриншотов и геометрии, **не точное сравнение каждого пикселя с эталоном** между Windows/Linux. Снимки также просмотрены визуально. CI сохраняет их отдельным артефактом `forge-performance-ui-screenshots`.

В скриншотах используется синтетическая история исключительно во временном тестовом профиле. В установленном приложении отображаются записи пользователя или пустые состояния.

Android: `:app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleDebugAndroidTest` — успешная локальная сборка. Kotlin JVM-тестов нет (NO-SOURCE).
