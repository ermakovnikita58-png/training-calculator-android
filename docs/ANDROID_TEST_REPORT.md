# Проверки FORGE Training 11.3.0

База обновления — 11.2.5, versionCode 23, коммит [2345209](https://github.com/ermakovnikita58-png/training-calculator-android/commit/234520966cfe51176e924979cd91480fac0eaba4). Проверочная ревизия [837dd7b](https://github.com/ermakovnikita58-png/training-calculator-android/commit/837dd7b).

## Локальные результаты

- `assembleDebug`, `assembleDebugAndroidTest`, `lintDebug` и `testDebugUnitTest` прошли. Android lint без ошибок. В JVM прошли 2 теста, контрольные цифры EAN/UPC и правила отзыва и истечения доступа.
- Отдельные сборки `assemblePlayDebug`, `assembleRustoreDebug` и JVM-тесты обеих конфигураций прошли. Платёжные SDK исключены из обычной сборки, для обеих магазинных сборок checkout выключен.
- Chromium и unit-тесты прошли локально. 61 проверка Nutrition Coach, 4 проверки импорта, 2 проверки штрихкодов и единиц порций, 2 проверки Supabase и RLS. Отдельно прошли тесты интерфейса при 320, 360, 390 и 412 CSS px, ограниченной сети, повторном запуске, отмене и подтверждении восстановления, ручном вводе при сбое OFF и конфликте облачной копии.
- Проверка арта обнаружила 556/556 локальных файлов, 0 отсутствующих и 0 битых. Исходные группы, оборудование и каталог не менялись. Отдельное экспертное подтверждение техники остаётся в прежнем статусе.
- Прямой запрос к Open Food Facts вернул товар `3017620422003`, единицу `g` и упаковку 400 г. Сквозной тест браузера использует фикстуру ответа и контролируемый сбой сети.

## APK

Пакет `ru.trainingcalculator.app`, versionCode 24, minSdk 24, targetSdk 36. Проверочный APK содержит встроенные модели ML Kit. В объединённом манифесте отсутствуют разрешения на точный будильник, foreground service, доступ к общему хранилищу и платежи. Видны разрешения на сеть, камеру, уведомления, вибрацию, три читаемых типа Health Connect и служебные разрешения WorkManager для сетевой очереди и перепланирования.

SHA-256 файла `FORGE-Training-11.3.0-debug.apk` — `64636ea3e5b7f0085f184dd7226591b677bafda859099159ebb5ec11f0264335`.

SHA-256 сертификата подписанта — `67a79818d74b1311adbd88bc9acc8a55290d86efcd58011fe74e3de957fe9fff`. Такой же сертификат у локального APK 11.2.5. CI пересобирает обе версии с одним ключом своего runner для проверки обновления.

## CI и устройство

- Браузерные проверки и Android-сборка прошли на ревизии `837dd7b`. [Web и данные](https://github.com/ermakovnikita58-png/training-calculator-android/actions/runs/42865440577), [Android build](https://github.com/ermakovnikita58-png/training-calculator-android/actions/runs/42865440685), [APK из CI](https://github.com/ermakovnikita58-png/training-calculator-android/actions/runs/42865440685/artifacts/13787546546).
- На эмуляторе API 35 прошли 11 тестов. Два проверили подготовку дневника в 11.2.5 и сохранение профиля, программы, тренировки, продукта и рецепта после `adb install -r` и перезапуска. Девять прошли при отключённых Wi-Fi и мобильных данных. Они покрыли крупную Unicode-копию Room и отказ при повреждении, системный Back, восстановление прокрутки и фильтров, сохранение черновика программы, возврат из системного выбора файла и ручной ввод после закрытия камеры. [Запуск Android upgrade](https://github.com/ermakovnikita58-png/training-calculator-android/actions/runs/42865440645), [логи и снимок экрана](https://github.com/ermakovnikita58-png/training-calculator-android/actions/runs/42865440645/artifacts/13785984389).
- Firebase Test Lab требует проекта владельца. Результата облачной матрицы пока нет.
- ADB не обнаружил физического устройства в рабочей среде.
