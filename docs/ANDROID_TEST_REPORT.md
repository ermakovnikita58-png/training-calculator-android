# Проверки FORGE Training 11.3

База обновления — 11.2.5, versionCode 23, коммит [2345209](https://github.com/ermakovnikita58-png/training-calculator-android/commit/234520966cfe51176e924979cd91480fac0eaba4). Базовая CI-сборка [42857527724](https://github.com/ermakovnikita58-png/training-calculator-android/actions/runs/42857527724).

- Chromium, 320/360/390/412 CSS px — сохранение, отмена восстановления, восстановление после перезапуска. Мост Android подменён тестовым адаптером, внешние запросы заблокированы.
- CI Android — отдельные задания компиляции APK, lint, JVM и сборки instrumentation APK.
- CI Android upgrade — чистый эмулятор, два APK подписаны одним ключом CI. Запись тестового профиля, программы, тренировки, продукта и рецепта в 11.2.5, затем `adb install -r`, перезапуск и сравнение значений. Основные UI Automator тесты запускаются после отключения Wi-Fi и мобильных данных.
- Firebase Test Lab — отдельная ручная матрица. Для запуска нужны проект и подтверждённый бюджет. Свидетельство запуска — отчёт конкретной матрицы.
- Физический Android — на момент аудита ADB не обнаружил устройств. Системный жест от края и поведение камеры проверяются отдельно на телефоне.
