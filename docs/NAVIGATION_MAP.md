# Карта навигации FORGE Performance UI

Пять корневых разделов используют существующие page id:

| Вкладка | ID | Вложенные области |
|---|---|---|
| Главная | home | Ближайшая/активная тренировка, быстрые действия, краткие сводки |
| Тренировки | workout | Упражнение, подходы, отдых, заметки, блины, карточка техники |
| Питание | nutrition | Дата/приёмы пищи, foodcatalog, meals, рецепты, nutritionCoach |
| Программы | plan | Редактор → день → выбор упражнения; library; cycles |
| Прогресс | progress | Сила / масса / объём / мышцы / питание; история |

Профиль (`profile`) и аккаунт/синхронизация (`account`) доступны из шапки и профиля. Существующие страницы не удаляются и не заменяются статическими макетами.

Back: IME обрабатывается Android → верхний диалог/карточка/sheet → вложенный редактор → предыдущий шаг Coach → внутренний стек → корневой системный выход. Несохранённый редактор запрашивает подтверждение. Активная тренировка продолжает храниться в state.active независимо от открытой вкладки.

Общий координатор navigation.js использует историю до 40 записей и один браузерный sentinel для popstate. Прямой возврат к уже посещённому экрану сокращает цикл; повтор текущего экрана не добавляет запись. При новом переходе — начало содержимого, при Back — предыдущее положение. Навигационный кэш отделён от forge_v2.

AndroidX OnBackPressedDispatcher получает готовность и возможность внутреннего Back заранее. Незагруженный/ошибочный JS не вызывает finish(). На корневом экране callback отдаёт системный выход Android. Отчёт воспроизведения прежних ошибок: NAVIGATION-11.1.1.md.

Установка, крайние жесты/predictive Back, IME, TalkBack и пересоздание процесса на физическом Android требуют отдельной проверки. Браузерные тесты не доказывают их работоспособность.

Активная тренировка: нижняя панель «Обзор / Записать подход» заменяет вкладки и не закрывает сессию. Список упражнений раскрывается в текущем экране. Компактные формы используют прежние modalback/n9Modal и общий Back; закрывающие кнопки несохранённого рецепта/редактора также проходят через координатор.
