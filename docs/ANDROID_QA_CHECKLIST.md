# FORGE Performance UI — проверка на тестовом Android

Не выполнено без подключённого устройства/эмулятора. Используйте тестовый телефон или эмулятор; перед проверкой пользовательского телефона экспортируйте JSON.

## Установка через ADB

```powershell
adb devices
adb install -r "FORGE-Training-11.2.0-debug.apk"
adb shell am start -n ru.trainingcalculator.app/.MainActivity
```

`-r` обновляет при совместимой подписи. Не использовать `pm clear`, `uninstall` или очистку приложения. Если подпись не совпала — сохранить установленное приложение и проверить APK/подпись.

## Сценарии и ожидаемое поведение

- [ ] Главная: реальные имя/дата/ближайшее занятие, недельные показатели и питание. Без записей — понятное пустое состояние.
- [ ] Пять вкладок: выбранное состояние, отсутствие перекрытия нижней панелью. Профиль/настройки доступны из шапки.
- [ ] Главная → программы → библиотека → карточка. Back закрывает карточку, затем возвращает в программы и на главную.
- [ ] Проверить крайний свайп до конца и его отмену отдельно на Android13/14/15/16; затем режим трёх кнопок. На главной разрешён системный выход, до неё данные не теряются.
- [ ] Открыть поле веса/повторов и клавиатуру. Изменить значение, первым Back скрыть IME. Записать подход в нижней панели одним нажатием.
- [ ] Активная тренировка: переход в обзор и обратно, отдых, индивидуальные настройки, RPE/заметки/блины. Поворот, сворачивание и перезапуск сохраняют результат и срок отдыха.
- [ ] Замена без отмеченных подходов работает; отмена выбора ничего не меняет. С отмеченными подходами замена не уничтожает результаты.
- [ ] Программа: создать, изменить день, переставить упражнения, скопировать день, выбрать программу. Отмена выхода из несохранённого редактора оставляет его открытым.
- [ ] Питание: порции, четыре приёма, избранное, рецепты, сохранённые рационы и история дат. Записи сохраняются после перезапуска.
- [ ] Coach: пять шагов, поддержание2600 и дефицит15% дают2210, применение только после подтверждения. Старые цели остаются в истории.
- [ ] Пять вкладок аналитики, периоды, текстовые таблицы графиков и пустые состояния соответствуют реальным записям.
- [ ] Экспорт/импорт JSON без потери программ/подходов/питания/рецептов/целей. Отмена и неверный JSON оставляют данные неизменными.
- [ ] Офлайн после установки: основные разделы и 556 иллюстрированных упражнений доступны. Barcode/онлайн-поиск честно требуют сеть/камеру и предлагают ручной путь.
- [ ] Размеры320/360/390/412dp, портрет/альбом, большой системный шрифт, TalkBack, отключение анимаций, вырезы и панели. Все главные кнопки доступны, ввод не перекрыт.
- [ ] Проверить выгрузку процесса после сворачивания и возврат: текущий экран/черновик не сбрасываются. Отдельно проверить разрешение камеры и системный выбор JSON-файла.

## Инструментальные тесты

```powershell
.\gradlew.bat connectedDebugAndroidTest
```

Три NavigationBackTest проверяют системный pressBack, JS-ошибку без закрытия и пересоздание Activity. Они не заменяют ручной predictive-жест. Записать модель устройства, API, WebView version, режим навигации, fontScale, результаты и скриншоты/видео. Не отмечать пункты без фактического выполнения.
