# FORGE 10.0.1 — изменения для проверки, 1 ноября 2026

## Изменения
- Сохранён проект FORGE 10 из предоставленного архива; исходный комплект лежит отдельно в Original-Kit.
- Исправлены Kotlin compilerOptions и Android-тема для API 24–26, добавлен Gradle Wrapper 8.13 с проверкой checksum.
- GitHub Actions собирает исходники из корня, проверяет JavaScript и изображения, выполняет assembleDebug, testDebugUnitTest, lintDebug и сохраняет APK. Удалённый запуск не выполнялся.
- Версия 10.0.1, код 11; applicationId, WebView origin и ключ хранения forge_v2 сохранены.
- Крупные анатомические карточки мышц. Пять растровых рисунков уменьшены до 480px WebP, остальные карточки векторные.
- 556 записей каталога имеют привязанные по имени иллюстрации двух положений: 367 используют лицензированные рисунки, 189 — собственные упрощённые схемы. Варианты одного движения могут использовать общий рисунок. Это не 556 независимо проверенных анатомических руководств.
- Исправлены кнопка возврата к мышцам, добавление из подробной карточки и выбор назначения упражнения (программа/активная тренировка).
- Пользовательские изображения имеют приоритет, неизвестным упражнениям предлагается добавить свой рисунок вместо случайной картинки.
- Функции тренировок, питания и статистики не удалялись. MainActivity не изменена; HTML изменён в местах каталога и обработчиков выбора.

## Проверки
- Node: синтаксис 10 встроенных блоков JavaScript и внешнего exercise-art.js — PASS.
- check-art.mjs: 556 привязок, существование локальных файлов, разные основные движения плеч, приоритет личного изображения, экранирование и пустой результат для неизвестного упражнения — PASS.
- Chromium, 390×844, локальная страница без сервера: меню мышц, карточка, добавление в тренировку, сохранение после reload, добавление в программу без изменения активной тренировки — PASS.
- Список названий и групп всех 556 упражнений сравнен с оригиналом — совпадает.
- В проверенном сценарии нет ошибок JavaScript, сломанных видимых изображений и горизонтального переполнения.
- Android: BUILD SUCCESSFUL (48 задач), lint 0 ошибок / 21 предупреждение. Итог сборки и lint записан в Review/build-visual.log; подпись и сведения APK — в Review/apk-verification.txt.
- Kotlin unit-тестов в проекте нет: NO-SOURCE не означает прохождение функциональных тестов.

## Ограничения
Не выполнялись установка на реальный телефон, обновление поверх пользовательской версии, полная регрессия питания/статистики/backup, камера, Supabase и подписанный release. Нужна визуальная и спортивно-техническая проверка полного каталога, особенно упрощённых схем. Не подтверждены все критерии дорожной карты; это локальная сборка для проверки, не выпуск в Google Play.

GitHub не изменялся, PR и подтверждённого CI-запуска нет. Документ docs/ROADMAP-reference.md сохранён как план следующих итераций; подписки, реклама и облачная инфраструктура в это обновление не добавлялись.

APK: 10.0.1 (11), minSdk24, targetSdk36, подпись v2 проверена. Все 938 файла assets в APK побайтово совпадают с исходниками.
