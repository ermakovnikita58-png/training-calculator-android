# Установка FORGE Training 10 с телефона Android

## Проверить приложение быстро

Скачай **forge-training-10.html**, открой через «Файлы → Загрузки → Chrome». Это автономный дневник. HTML с браузерным хранилищем и установленное приложение хранят записи по разным адресам — перед переносом обязательно экспортируй JSON из старой версии.

## Собрать APK без компьютера

1. Открой github.com и создай пустой репозиторий. Старый репозиторий тоже подходит, но удали старые ZIP-файлы проекта, чтобы workflow случайно не выбрал предыдущую версию.
2. Загрузи **forge-training-10-android-project.zip** как один файл в корень репозитория (не обязательно распаковывать).
3. Выбери **Add file → Create new file** и назови его **`.github/workflows/build.yml`**.
4. Вставь туда содержимое файла **forge-build-v10.yml** из комплекта. Если такой workflow уже есть, обнови его содержимое целиком.
5. GitHub → Actions → **Build FORGE Training 10** → Run workflow → дождись зелёной отметки.
6. Скачай **forge-training-10-debug-apk** из Artifacts, распакуй ZIP и установи `app-debug.apk` на Android. Android может спросить разрешение установки из источника — предоставь его только для проверенной собственной сборки.
7. Для перехода со старого HTML или APK: в старом приложении **Профиль → Сохранить JSON**, затем в новой версии **Профиль → Восстановить JSON**.

## Готовый APK в этом комплекте?

Нет: без Android SDK и Gradle на рабочем компьютере APK здесь не собран. Android ZIP содержит *исходный проект* и проверяемый workflow. Не называй его APK, пока GitHub Actions не выпустит `app-debug.apk`.

## Облачный вход

Почта и пароль подключаются через **Supabase**, только после создания собственного проекта и применения SQL из `supabase-schema.sql`. Google OAuth для PWA требует HTTPS-сайт и настройки провайдера; внутри Android WebView не включён. См. `ОБЛАКО_НАСТРОЙКА.md`.

## Если загрузка HTML не начинается

Используй **forge-training-10-html.zip**. В «Файлы» распакуй его и открой `forge-training-10.html` через Chrome.
